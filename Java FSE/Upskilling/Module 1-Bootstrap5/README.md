# Thendral Nagar Event Portal

This project is a local community event portal built with Bootstrap 5. The pages use a consistent theme for event notices, volunteer registration, local dashboards, cards, icons, interactive components, and a custom theme.

## Theme Notes

- The portal stays local to Thendral Nagar and avoids outside-city references.
- Shared styling lives in `assets/css/site.css` so the pages read as one project instead of separate exercises.
- The custom theme is already compiled into `dist/custom-bootstrap.css`.

Open `index.html` directly in a browser to view the portal.
