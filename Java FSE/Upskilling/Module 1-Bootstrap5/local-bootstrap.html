Local portal files

Local files in a working sample

This sample event notice uses local files: vendor/bootstrap/css/bootstrap.min.css and vendor/bootstrap/js/bootstrap.bundle.min.js.

The local bundle is working. This collapse panel can open even without CDN JavaScript.

Why the local copy matters

The portal can still run on a classroom laptop with no network access because the CSS and JS are copied into the project and linked directly from the vendor folder.

Local file check

  • CSS comes from the downloaded styles folder.
  • Plugins come from the bundled JS file.
  • Icons remain available from the copied icon package.
